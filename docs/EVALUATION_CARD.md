# Evaluation card: Taadeel (تعديل)

Taadeel tracks amendments to UAE federal legislation and produces article level diffs and point in time views. It is a research and navigation tool, not legal advice. The official Arabic text published by the competent authority prevails.

## Intended use and out of scope uses

* Intended: locating what changed between versions of a law, reading the text as of a date with its source and retrieval date, and testing alignment and diff methods under a pre registered protocol.
* Out of scope: stating the law, legal advice, compliance decisions, litigation, any use that treats a point in time answer as authoritative, and any use on UAE law, since none is loaded or validated.

## Data

* Synthetic: generated test laws, labelled synthetic on every response and kept out of real views.
* UK English legislation from legislation.gov.uk, Open Government Licence v3.0, 7 Acts, England and Wales view, body sections only. Schedules are excluded.
* Arabic: labelled synthetic strings, plus counts only from one Arabic Wikisource law page whose text is not committed.
* No UAE data. The official portal returned HTTP 403 on robots.txt; this was recorded and not worked around. A permission request is drafted and has not been sent.

## Limits

* Nothing is validated on UAE law or on real Arabic legal text. UK numbers say nothing about UAE law.
* Synthetic results measure code on generated text. The Arabic stress set and normalisation v2 were written after the cases were seen, so that score is by construction.
* UK one day windows are easy cases. UK ground truth is editorial, not a legal original. Hand checks were done by the author, not by a lawyer.
* Schedules, devolved material and prospective changes are excluded. Amendment pattern recall is low and the Arabic lexicon is unvalidated.
* Engine v1 files are hash locked; evaluations were pre registered and run once, and misses are reported with hits.

## How to reproduce

```
python -m taadeel.heldout
python -m taadeel.heldout_v2 run          # refuses a second run
python -m taadeel.timeline_v2 run
python -m taadeel.uk_amending2 run
python -m taadeel.arabic_stress
python -m taadeel.akn_export validate DIR # DIR holds the OASIS schema files
python -m taadeel.report
```

Each command writes only its own result files under `results/`. `python -m taadeel.report` regenerates this card from them.
